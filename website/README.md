# mpvDanmaku Website

Next.js website for the independent mpvDanmaku Android application.

## Configuration

```text
NEXT_PUBLIC_GITHUB_REPOSITORY=owner/repository
NEXT_PUBLIC_SITE_URL=https://example.com
```

Without a repository setting, GitHub release and contributor requests are disabled instead of falling back to mpvEx.

## Development

```bash
pnpm install
pnpm dev
pnpm validate
pnpm build
```
